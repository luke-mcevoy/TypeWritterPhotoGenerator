# README media

These examples use Carriage's actual renderer and interface. The artwork has not been retouched or generated with another image model. Images have been resized and compressed for GitHub; presentation frames and labels were added to the renderer examples.

| Asset | Source and settings |
| --- | --- |
| `photo-to-type.jpg` | Photograph by [Thomas K on Pexels](https://www.pexels.com/photo/facade-of-a-red-brick-building-14413019/). Source beside Vibrant color, 180 columns, 70% color. |
| `glyph-detail.jpg` | Enlarged crop of the same brick-building rendering. |
| `color-amount.gif` | Photograph by [Arnauld van Wambeke on Pexels](https://www.pexels.com/photo/path-in-forest-in-sunlight-24706137/). Vibrant color, 180 columns; animation interpolates the renderer's lossless 0% and 100% color endpoints. The title and slider are presentation graphics, not a screen recording. |
| `studio.jpg`, `crop.jpg` | Browser captures of the local Studio using the Thomas K photograph. Default Vibrant color, 150 columns, 70% color; the crop screenshot shows a square selection before applying it. |
| `wall-lucid.jpg` | [Lucid, posted by Luke](https://carriage-typewriter.fly.dev/p/43), saved public drawing downloaded September 18, 2026. |
| `wall-sf.jpg` | [SF, posted by Luke](https://carriage-typewriter.fly.dev/p/33), saved public drawing downloaded September 18, 2026. |

Renderer examples come from the validated `experiments.illustration_study` gallery generated for code commit `f847c2d`. They use its **Vibrant** baseline, not the illustration preview: scale 2, contrast 1.4, simplify 0.55, pressure 0.88, overstrike 1, dark fill 100%, seed 7, Classic keys, White paper, Carbon ink. The renderer hashes in that gallery's manifest matched the checkout when these assets were prepared.

The two wall examples are existing saved posts, with their original settings. They are not claims about how today's defaults would render those photographs. None of James Cook's artwork is reproduced in these assets.
